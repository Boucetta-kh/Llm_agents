# 🤖 AI Software Team Simulator (DeepSeek Model)

## 📌 Description
This project simulates a real-world software development team using AI agents powered by DeepSeek models.

The system includes:
- 🧑‍💼 Project Manager Agent
- 🎨 Frontend Developer Agent
- ⚙️ Backend Developer Agent

These agents collaborate to plan, design, and generate software components automatically.

---

## 🚀 Features
- Multi-agent collaboration (PM, Frontend, Backend)
- Task planning and role assignment
- Automatic API design
- Frontend and backend code generation
- AI-powered communication using DeepSeek model

---

## 🧠 Technologies
- Python
- DeepSeek (LLM model)
- Ollama / local LLM execution
- FastAPI (backend)
- React (frontend - planned)

---

## ⚙️ How It Works
1. The Project Manager defines the application features
2. Backend Agent generates API structure
3. Frontend Agent builds UI components
4. Agents communicate using LLM prompts
